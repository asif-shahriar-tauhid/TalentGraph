Mission & Scope

Join our core telemetry infrastructure team building low-latency stream processing pipelines handling over 2M commits and event traces daily. You will anchor system reliability, architect fault-tolerant ingestion services, and collaborate closely with open-source distributed tracing contributors.

  • Mentor senior and mid-level engineers through rigorous code reviews and telemetry-driven design docs.
  • Partner with candidate assessment engineers to benchmark live coding sandbox environments.
